# Official vendor campaign watches

Official Norwegian manufacturer stores are useful when temporary campaigns make new hardware competitive with refurbished systems.

Initial watches:

- Dell Norway
- Lenovo Norway

These are kept separate from refurbished-market observations.

## Campaign model

Capture, when explicitly available:

- normal price
- campaign price
- discount percentage
- coupon/code
- campaign expiry
- exact configuration
- warranty
- stock/delivery status

Never manufacture a normal price or expiry from marketing text. A coupon that requires conditions must preserve those conditions.

## Scoring

A new machine should not win merely because a marketing discount percentage is large. Later scoring compares actual NOK cost and configuration, while allowing explicit value for warranty, platform age, efficiency and expected lifecycle.

Relevant families include Dell Micro/Precision/workstation systems and Lenovo ThinkCentre Tiny/ThinkStation/workstations.
