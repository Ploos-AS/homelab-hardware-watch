# Enterprise opportunity scoring

M2 introduces role-specific technical scoring for enterprise candidates.

## Proxmox compute

Rewards:

- 32/64/128+ GB RAM
- dual CPU where explicitly detected
- 10/25GbE
- comparable NOK price when available

## Storage

Rewards:

- LFF capacity, especially 8+ and 12+ bays
- HBA rather than merely the presence of a RAID/storage controller
- 10/25GbE
- useful RAM capacity
- comparable NOK price when available

## Currency safety

Raw EUR prices are never compared numerically with NOK thresholds. European candidates can receive technical-fit scores in M2, but price points are withheld until a canonical delivered-NOK value exists.

This is deliberate: a EUR catalogue price does not yet include the complete Norway import/shipping/tax model.
