# Norwegian source matrix

| Source | M1 mode | Main value |
|---|---|---|
| IT Garasjen | structured storefront | servers, workstations, components |
| Axentra | structured storefront | enterprise servers/storage/networking |
| ScandicTech | WooCommerce category | Mini PCs and refurbished desktops |
| Rebuild IT | structured storefront | Tiny/Mini desktops, components |
| TekAgain | manual lead / buyer list | bulk enterprise servers, RAM, networking, SSD/GPU |
| BruktTech | watch/manual for now | mostly laptops/client devices |
| FINN.no | planned marketplace adapter | opportunistic private/business listings |

## Current observations

ScandicTech has a dedicated Mini PC category, making it useful for the N100/N150 comparison class.

Rebuild IT exposes stock counts and detailed specifications on product pages and is therefore useful for Tiny/Mini price history.

TekAgain is intentionally represented as a manual sourcing lead. Its buyer flow offers server RAM, complete servers, networking, SSD/GPU and other bulk business IT before public listing. That is valuable, but it is not equivalent to a conventional continuously scrapeable shop.

BruktTech currently appears client/laptop-heavy, so it remains lower priority until relevant desktop/server inventory appears.

FINN needs its own marketplace strategy, including deduplication and seller/listing lifecycle handling.
